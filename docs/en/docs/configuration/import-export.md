# :material-cog-outline:{ .md .middle } Import - Export settings

Importing or exporting panel settings via Files or BPB Panel peers.

!!! info "Adding a subscription to a client"
    On the subscription pages each client has a one-click add button. It imports the subscription straight into the app on your device's OS — or copies the link when that client does not run on your OS. See [Supported Clients](../usage/supported-clients.md).

!!! tip "Which settings are shared?"
    All settings will be exported or imported this way except `VLESS UUID`, `Trojan Password` and `Panel - Subscription Path` for your privacy.

## Remote Settings

You can easily share your panel settings with a BPB peer or import others' settings.

## File Settings

This method downloads or uploads settings via files.
