# :material-telegram:{ .md .middle } پروکسی وب تلگرام (Telegram Web Proxy)

در BPB یک قابلیت مستقل به نام **Telegram Web Proxy** اضافه شده که اتصال تلگرام را از طریق یک Relay مبتنی بر WebSocket روی Cloudflare Worker برقرار می‌کند. این قابلیت با Telegram Bot، پروتکل‌های VLESS و Trojan و لینک‌های اشتراک BPB متفاوت است و یک MTProto Proxy خام و مستقل نیست.

!!! warning "فقط Workers"
    این قابلیت به Durable Object کلادفلر نیاز دارد و فقط روی **Cloudflare Workers** قابل استفاده است. در استقرار Cloudflare Pages پشتیبانی نمی‌شود.

## اتصال تلگرام

1. نسخه‌ای از BPB Worker را مستقر کنید که قابلیت Telegram Web Proxy را دارد و وارد پنل شوید.
2. بخش **Telegram Web Proxy** را بعد از **Subscriptions** و قبل از **DNS over HTTPS** پیدا کنید.
3. لینک اتصال نمایش‌داده‌شده در همان بخش را کپی کنید یا باز کنید. پنل این لینک را برای مدیر واردشده دریافت می‌کند و نیازی نیست آن را دستی بسازید.
4. لینک را روی دستگاهی که تلگرام نصب است باز کنید و پیام تلگرام برای اضافه کردن پروکسی را تأیید کنید.
5. پروکسی اضافه‌شده را در تلگرام فعال کنید و بارگذاری پیام‌ها را بررسی کنید.

این لینک از قالب رسمی `t.me/webproxy` استفاده می‌کند و شامل دامنه Worker و Secret پروکسی است. **کل لینک را مانند رمز عبور محرمانه نگه دارید** و آن را عمومی یا برای افراد غیرقابل‌اعتماد ارسال نکنید.

## تست اتصال

روی دکمه **Test** در بخش Telegram Web Proxy بزنید. پنل فقط نتیجه نهایی را نمایش می‌دهد:

- **Success (موفق)** — بررسی‌های سمت سرور با موفقیت انجام شده‌اند.
- **Error 21xx** — یکی از بررسی‌ها شکست خورده است. کد خطا محدودهٔ مشکل را مشخص می‌کند؛ جدول پایین را ببینید.

این تست درخواست احراز هویت‌شده، در دسترس بودن Worker، اتصال Binding با نام `SESSIONS`، مقدار و قالب `PROXY_SECRET`، راه‌اندازی Durable Object و اتصال خروجی TCP به یکی از نقاط دادهٔ تلگرام روی پورت `443` را بررسی می‌کند.

!!! info "تست چه چیزی را تضمین نمی‌کند؟"
    این دکمه یک بررسی تشخیصی سمت سرور است. موفق بودن اتصال TCP به‌تنهایی به معنی انجام کامل Handshake کلاینت تلگرام یا تضمین اتصال همهٔ کلاینت‌ها و شبکه‌ها نیست. لینک را در تلگرام اضافه کنید و اتصال واقعی را هم امتحان کنید.

## بازنشانی Secret

با انتخاب **Reset Secret** یک Secret تصادفی جدید ساخته و Secret مربوط به Worker در Cloudflare به‌روزرسانی می‌شود. پس از موفقیت، لینک اتصال جدید در پنل نمایش داده می‌شود.

لینک قبلی حاوی Secret قدیمی است و دیگر نباید از آن استفاده کنید. پروکسی ذخیره‌شده در تلگرام را با لینک جدید جایگزین کنید. فقط در صورت نیاز Secret را Reset کنید، چون لینک‌های قبلی با هر بار بازنشانی نامعتبر می‌شوند.

## کدهای خطا

| کد | معنی |
| :--- | :--- |
| `2101` | نشست پنل وجود ندارد، منقضی شده یا احراز هویت نشده است. دوباره وارد پنل شوید. |
| `2110` | Telegram Web Proxy در دسترس نیست. این قابلیت به Workers و Binding به نام `SESSIONS` نیاز دارد و روی Pages پشتیبانی نمی‌شود. |
| `2120` | مقدار `PROXY_SECRET` تنظیم نشده یا قالب آن معتبر نیست. از **Reset Secret** استفاده کنید یا تنظیمات Worker را بررسی کنید. |
| `2121` | بررسی سلامت یا راه‌اندازی Durable Object ناموفق بوده است. Binding با نام `SESSIONS` و Migration آن را بررسی کنید. |
| `2122` | Worker نتوانسته اتصال TCP تشخیصی به نقطهٔ دادهٔ تلگرام روی پورت `443` برقرار کند. |
| `2198` | Cloudflare درخواست بازنشانی Secret را نپذیرفته است. تنظیمات حساب Cloudflare و سطح دسترسی Token سمت سرور را بررسی کنید. |
| `2199` | هنگام پردازش درخواست، خطای شبکه یا خطای پیش‌بینی‌نشده رخ داده است. |

این کدها مرحله‌ای را که پنل گزارش کرده مشخص می‌کنند؛ آن‌ها راهنمای تشخیص اولیه هستند و لزوماً تمام علت‌های احتمالی مشکل سمت کلاینت را پوشش نمی‌دهند.

## نکات استقرار

این یکپارچه‌سازی از موارد زیر استفاده می‌کند:

- کلاس Durable Object با نام `WebProxySession`
- Binding فضای نام Durable Object با نام `SESSIONS`
- ذخیره‌سازی SQLite در Durable Object
- برچسب Migration با نام `v1-twp` برای ایجاد اولیهٔ کلاس SQLite
- Secret مربوط به Worker با نام `PROXY_SECRET`

Migration اولیهٔ SQLite هنگام فعال‌سازی قابلیت روی هر Worker جدید باید فقط یک بار اعمال شود. در به‌روزرسانی‌های بعدی باید وضعیت Migration قبلی حفظ شود و کلاس SQLite دوباره ساخته نشود. Secret پروکسی را در مخزن کد، HTML پنل، JavaScript سمت کاربر یا Logها قرار ندهید.

## محدوده و محدودیت‌ها

- Telegram Web Proxy یک روش اتصال مستقل برای تلگرام است و جایگزین قابلیت‌های VLESS، Trojan، Warp یا DoH در BPB نیست.
- این قابلیت تونل عمومی UDP نیست؛ تماس صوتی/تصویری تلگرام و ترافیک وابسته به UDP توسط آن ارائه نمی‌شود.
- دکمه **Test** پیش‌نیازهای سمت سرور را بررسی می‌کند؛ لینک تولیدشده را حتماً با یک کلاینت واقعی تلگرام هم آزمایش کنید.
